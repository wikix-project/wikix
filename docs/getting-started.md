# Getting started

Wikix exports your X bookmarks through the official X API. Setup differs by operating system, so
choose the computer you will use to run Wikix:

Already comfortable with developer tools? Use the [Quick setup](quick-setup.md) for the shortest
command-first path, or continue with an operating-system guide below.

## Choose your operating system

- [macOS](getting-started-macos.md) — use Terminal and macOS Keychain.
- [Windows](getting-started-windows.md) — use PowerShell and Windows credential storage.
- [Linux](getting-started-linux.md) — use a desktop terminal and a Secret Service-compatible
  credential store.

Each guide starts with X developer access and finishes by showing where Wikix saved your
bookmarks. You do not need prior Python, Git, or command-line experience.

> [!IMPORTANT]
> Wikix uses API credits. Read the cost step in your operating-system guide before installing or
> syncing.
