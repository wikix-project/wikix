What you keep

Useful files, without a hosted library.

Markdown for ordinary tools.

One file per current bookmark, ready for Obsidian, text search, and version control.

JSONL for private workflows.

A deterministic machine-readable collection for scripts, retrieval, and local analysis.

Careful updates.

Personal annotations survive normal syncs, while conflicts and incomplete snapshots do not silently replace the last good export.

How it works

Your app, your collection, your files.

Official X API→ Wikix on your computer→ Markdown + JSONL

  1. 1. Connect Provide the client ID from your own X developer app.
  2. 2. Authorize Sign in with X in your system browser.
  3. 3. Sync Write the current collection to a directory you choose.

Before you start

A local tool with real API requirements.

  • Stable release Install Wikix 1.0 from source with Python 3.12 or newer.
  • X developer access Bring your own approved X developer app and API credits.
  • Complete scans Every sync scans the complete current bookmark collection and may incur X API charges.

The Step-by-Step Guide covers OAuth setup, current cost cautions, and spending limits.

Private and careful by design

Your collection stays under your control.

No Wikix server or telemetry.
Bookmarks are written directly to the local directory you choose.
Credentials stay local.
OAuth tokens use your operating-system credential store.
The last good export is protected.
Incomplete snapshots do not replace it. Managed-content conflicts are reported instead of overwritten.

Read the privacy policy and security policy.
