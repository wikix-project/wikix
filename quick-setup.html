A command-first path

Quick setup

Have your X developer app ready, run five commands, and keep the resulting Markdown notes and JSONL in a collection directory you control.

Need the full context? Open the Step-by-Step Guide.

Before you run anything

Before you begin

You need Python 3.12 or newer, an X account, an approved X developer project and app, OAuth 2.0 Authorization Code with PKCE access, API credits, and a spending limit. Replace YOUR_CLIENT_ID and the collection path with your own values.

Check the cost first

Every sync scans the complete current bookmark collection and may incur X API charges. The first sync cannot estimate a count, so review current pricing in the Developer Console before confirming the API call.

Five commands

Run these commands

Run them in order. The collection directory is created by wikix init.

uv tool install --python 3.12 git+https://github.com/wikix-project/wikix.git
wikix init ~/Documents/MyVault/X-Bookmarks --client-id YOUR_CLIENT_ID
cd ~/Documents/MyVault/X-Bookmarks
wikix auth login
wikix sync

After the first sync

What happens next

Wikix opens X in your system browser for local OAuth, writes one Markdown note per current bookmark, and records deterministic JSONL in the collection directory. Personal notes are preserved across normal syncs.

For OAuth callback details, collection layout, recovery behavior, and later sync options, read the Step-by-Step Guide or the GitHub Quick setup source.
