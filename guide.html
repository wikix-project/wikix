A local setup path

Step-by-Step Guide

Go from an approved X developer app to a local collection of Markdown notes and JSONL. Wikix uses your own credentials, your own API access, and a directory you control.

Prefer the shortest path? Open Quick setup.

Before you begin

Have the account access and budget ready.

You need Python 3.12 or newer, an X account, an approved X developer project and app, OAuth 2.0 Authorization Code with PKCE access, API credits, and a spending limit. Your system browser must be able to reach 127.0.0.1, and each X account needs its own collection directory.

Cost check

A complete scan estimates owned reads at bookmark count × $0.001 when a previous successful count is available. The first sync cannot estimate a count, and current X pricing in the Developer Console is authoritative. Every sync scans the full collection; --rich and --folders can add unpredictable charges.

Step 1

1. Create your X app

In the X Developer Console, create or select a project and app approved for your account. Confirm that the app can use the bookmark endpoint. Console labels, prices, and policy terms can change, so the current console and bookmark endpoint documentation are the source of truth.

Keep the app owned by you

Wikix is a local tool. It does not provide hosted credentials or a shared X app for your collection, and it does not scrape bookmarks through a browser.

Step 2

2. Configure OAuth

Configure the app as a public native or desktop client using Authorization Code with PKCE.

Callback details

Callback: http://127.0.0.1:8765/callback

Client secret: not used by Wikix.

Scopes

bookmark.read, tweet.read, users.read, and offline.access.

Copy the OAuth 2.0 client ID. Do not put a client secret into Wikix.

Step 3

3. Install Wikix

Install from the public source repository with uv:

uv tool install --python 3.12 git+https://github.com/wikix-project/wikix.git

Step 4

4. Create a collection

Choose one empty local directory for one X account. The default callback port is 8765. 

wikix init ~/Documents/MyVault/X-Bookmarks --client-id YOUR_CLIENT_ID

When the callback port is busy

Choose a port and register its exact callback URI in the X app before initializing:

wikix init ~/Documents/MyVault/X-Bookmarks --client-id YOUR_CLIENT_ID --callback-port PORT

Step 5

5. Authenticate

Change to the collection directory and start login from there.

cd ~/Documents/MyVault/X-Bookmarks
wikix auth login

What login does

Wikix opens X in the system browser, validates OAuth state, receives the localhost callback, and binds the collection to the authenticated account. Access and refresh tokens are stored in the operating-system credential store.

Step 6

6. Run your first sync

The default profile is lean. Start from the collection directory:

wikix sync

Review before the API call

The first sync has no previous collection count, so it cannot estimate a cost. Wikix shows its cost assumptions and asks for confirmation before making API calls.

Step 7

7. Inspect and maintain your export

A collection contains bookmarks/ Markdown notes, bookmarks.jsonl, _review/, and .wikix/ configuration and state. Generated note content is deterministic; only the Personal notes region is user-owned.

Later syncs

Run later scans from the collection directory, or select it explicitly from elsewhere:

wikix sync
wikix sync --rich
wikix sync --folders
wikix sync --rich --folders
wikix --collection ~/Documents/MyVault/X-Bookmarks sync

The --rich and --folders options are independent and may create additional charges. --yes skips confirmation, not billing.

Headless environments

Inject WIKIX_ACCESS_TOKEN and optionally WIKIX_REFRESH_TOKEN from a secret store, then run wikix --collection PATH sync. Never put tokens in shell history, .env files, CI logs, or source control.

Recovery and conflicts

When a bookmark is removed, an unannotated note is deleted and an annotated note moves to _review/. Malformed Personal notes markers or managed-content edits are reported as conflicts and left untouched. Compatible staging resumes interrupted scans, and incomplete snapshots do not replace the existing export.

When setup stops

Troubleshooting

Credentials or rejected scopes

Run wikix auth login from the collection directory and confirm the four required scopes in the X app.

Callback mismatch

Register the exact http://127.0.0.1:PORT/callback URI, update the collection callback port, and log in again.

Credits, 403, or 429 responses

Check app approval, endpoint access, credits, and spending limits. Wikix waits for X's reset time after a rate limit.

See the collection state

wikix status
wikix auth logout
